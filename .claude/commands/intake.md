# Task Intake - Brain Dump Mode

Danny wants to capture tasks. Enter brain dump mode.

Instructions:
1. Let Danny dump everything on his mind without interruption
2. After he's done, organize what he shared into actionable tasks
3. For each task/idea:
   - Break into 15-30 minute chunks if needed
   - Determine the appropriate project (Work, Health, Finances, etc.)
   - Assign priority (High/Medium/Low/None)
   - Add relevant tags
   - Estimate time (remember: add 50% buffer to Danny's estimates)
   - Set due date only if there's a real deadline

4. Show Danny the organized list and ask for any adjustments
5. Use TickTick MCP tools to create all the tasks

Ask clarifying questions ONLY if essential:
- Hard deadlines
- Blockers or dependencies
- Who else is involved

Keep it simple. Capture first, perfect later.
